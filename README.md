# ghostCarnival

Controls

Main Menu - Use Mouse to hover over and click the 'PLAY' button

Hub - Use "WASD' keys to control the ghost and move around the hub.
  Approaching Booths 
Top Left - Press 'ENTER' key after reading instructions to enter the room.
Top Right - Press 'ENTER' key after reading instructions to enter the room.
Bottom Left - Press 'ENTER' key after reading instructions
  Second message - Use Mouse to hover over and press the 'Enter Room' or 'Back to Hub' buttons
Botto Right - Press 'ENTER' key after reading instructions to enter the room.

Wall Phase Level (Top Left)
Use mouse to phase through the walls. 
  If player fails to phase through any of the walls - Fail message appears. Press 'Enter' key to advance back to hub.
  If players phases through all the walls - Win message appears. Press 'Enter' key advance back to hub.

Ghost Race Level (Top Right)
Use 'SPACEBAR' key to move your ghost. 
  Player needs to repeatedly press 'SPACEBAR' for ghost to move. 
    If player wins the race - win message appears. Use Mouse to hover over and click 'BACK' button to return to hub.
    If ghost wins the race - fail message appears. Use MOuse to hover over and click 'BACK' button to return to hub.

Collect Chest Level (Bottom Left) 
Use 'WASD' keys to move around the map
  Approach Chest to collect reward. 
  After all chest have been collected - message appears. Press 'SPACEBAR' to return to hub.

 Prize Room (Bottom Right)
 Use Mouse to hover over the different items and click on item to purchase. 
   Player can only buy an item if the player has enough currency.
   Once Item has been purchased, they'll see the ghost color in the hub and chest room. 
   Upon purchase item is removed from the store. 
 Use Mouse to hover over and press 'Exit Shop' button to return to hub.

Game Objective
Play through the mini games and collect chest from the chest room to gather enough points to buy all the ghost skins.
